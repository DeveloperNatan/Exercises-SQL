# SQL Exercises

Repositório para prática e estudo de SQL, com exercícios isolados de consultas, criação de tabelas e manipulação de dados.

## Sobre

Este repositório reúne exercícios de SQL feitos durante meus estudos de Modelagem de Dados e Engenharia de Software. Cada exercício é independente e serve para praticar conceitos como:

- Criação de tabelas (DDL)
- Consultas (SELECT, WHERE, JOIN, GROUP BY)
- Manipulação de dados (INSERT, UPDATE, DELETE)
- Chaves primárias e estrangeiras
- Subqueries e agregações

## Tecnologias

- PostgreSQL

## Como usar

1. Clone o repositório
2. Rode os scripts `.sql` no seu banco de dados local ou remoto
3. Explore os comandos e resultados de cada exercício
